TouchWiz Access user guide

Use a Windows Precision Touchpad with NVDA to navigate by element type, activate controls and switch between open windows.

Installation and startup

TouchWiz Access requires NVDA 2026.1 or later and a compatible Windows Precision Touchpad.

  1. Open the touchwiz-access.nvda-addon package and confirm installation.
  2. Restart NVDA.
  3. Press NVDA+Alt+Shift+T and listen for the announcement that touchpad navigation is on. Press the same shortcut to turn it off.

While TouchWiz is on, supported Windows tap, scroll, zoom, and three- and four-finger system gestures are temporarily suspended. TouchWiz restores the previous settings when it turns off. TouchWiz announces at startup if suspension is unavailable.

Basic gestures

Swipe right or left with one finger
Go to the next or previous item of the selected type. In Default navigation, swiping right sends Down Arrow and swiping left sends Up Arrow.
Swipe down or up with one finger
In Default navigation, these gestures send Tab and Shift+Tab respectively.
Turn the rotor with your thumb and index finger
Turn clockwise as if twisting a bottle cap to select the next type. Turn counterclockwise to select the previous type. Lift both fingers before turning again.
Double-tap with one finger
Send Enter to the current item. This gesture is supported on Windows 11 24H2 and later.
Double-tap with two fingers in the top or bottom third
Keep both fingers in the same region for both taps. The top sends Ctrl+Home and the bottom sends Ctrl+End. In NVDA browse mode these move to the beginning or end of the active document. NVDA announces the boundary after confirming that the browse cursor reached it. In other windows the focused control determines what the shortcut does. This gesture requires Windows 11 24H2 or later and successful suspension of the native two-finger tap.
Double-tap with three fingers
Copy the current selection and announce “Content copied”. The keyboard equivalent is Ctrl+C.
Triple-tap with three fingers
Paste from the clipboard and announce “Content pasted”. The keyboard equivalent is Ctrl+V.
Swipe from left to right with three fingers
Go to the next open window in the Windows window order. The keyboard equivalent is Alt+Esc.
Swipe from right to left with three fingers
Go to the previous open window in the Windows window order. The keyboard equivalent is Alt+Shift+Esc.

Move three fingers together and lift them to switch windows. Each swipe makes one switch. Windows determines the order. You can use Alt+Tab to restore a minimized window. After switching, one-finger gestures apply to the active window.

Rotor and element types

Documents that support browse mode

Turn the rotor until NVDA says Text fields, for example. Swipe right to run E or left to run Shift+E. The NVDA browse cursor moves in the active document. Double-tap when you want to activate the current item. After typing, a navigation gesture returns to browse mode.

Swipe right to use the key listed below. Swipe left to use the corresponding Shift command.

  • Text fields E, buttons B, links K, form fields F, landmarks D.
  • Headings H, heading levels 1 through 9, lists L, list items I, tables T.
  • Checkboxes X, radio buttons R, combo boxes C, visited links V, unvisited links U.
  • Text outside links N, block quotes Q, separators S, frames M, images G.
  • Embedded objects O, annotations A, text paragraphs P, spelling errors W.

Windows apps and File Explorer

In Keyboard focus, swiping right and left sends Tab and Shift+Tab. In Arrow keys, the swipe direction matches the arrow key. In File Explorer tabs, swiping right and left sends Ctrl+Tab and Ctrl+Shift+Tab.

You can also select text fields, buttons, links, form fields, checkboxes, combo boxes, lists, list items, tree views, tree items, tables, table rows, table cells and toolbars. Keyboard focus moves among matching controls in the active window. When a container cannot take focus, its first eligible child is used. Matches depend on the app’s accessibility support.

To return to the general gestures, use the rotor to select Default navigation.

Settings and profiles

Open Preferences → TouchWiz Access from the NVDA menu. Use Ctrl+Tab to change tabs and Tab to move among controls.

  • General. Choose the activation shortcut and the language for the interface and guide. Follow NVDA uses the NVDA language. Turkish and English are included. English is used for other languages.
  • Open user guide in the General tab opens the offline guide in your browser using the selected language. To change the interface language, save with OK and reopen settings.
  • Gesture customization. Choose Global defaults or add a profile for an app such as notepad.exe. Select a gesture and choose Assign action. An application’s own assignments take priority while it is active. You can also reassign or disable the three-finger swipes.
  • Settings and layouts. Use the General tab to export or import settings, custom gestures and application profiles as a JSON file. Save imported settings with OK.

Gesture wizard

  1. Open Create a gesture → Start gesture wizard. The detector starts automatically on the recording page.
  2. Swipe with one to five fingers, tap once, twice or three times, or draw a continuous shape with one finger. Lift all fingers at the end of the sample. The supported finger count depends on your hardware.
  3. After the first sample is announced, select Next and repeat it. The wizard compares the samples and asks for confirmation if they match a built-in gesture.
  4. Name the gesture and choose a global or application profile. NVDA action and Windows shortcut provide preset lists. For a Keyboard shortcut, select modifiers and a main key. To Launch an application, choose an executable file.
  5. Repeat the gesture on the final page to test recognition, then select Save gesture. Close settings with OK. If you selected the action test, switch to the target app and perform the gesture within 30 seconds.

Troubleshooting

  • A gesture is not detected. Check that TouchWiz is on. Move your fingers together and lift them after each attempt. For a three-finger swipe, start in a horizontal direction.
  • A three-finger swipe performs another action. Check the active application profile and the global assignments. If TouchWiz announced that Windows gestures could not be suspended, check the Windows touchpad settings as well.
  • No item of the selected type is found. Check the active window and the selected rotor type. In a document, try the corresponding keyboard quick navigation command. Select Default navigation to return to general gestures.

See the NVDA 2026.1 quick navigation guide for standard browse mode commands.
